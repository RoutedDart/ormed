# Installation

Install the Ormed runtime and one database driver first. This page deliberately
stops before project scaffolding and code generation so you can choose the
smallest path that fits your project.

Before you start: Dart SDK `>= 3.12.0`; A Dart package or application where you can run `dart pub`; A choice of database driver.

## Add Ormed and a Driver

Choose the driver for the database you will connect to:

<Tabs groupId="install-driver" defaultValue="sqlite">
  <TabItem value="sqlite" label="SQLite (recommended)">

```yaml
dependencies:
  ormed: ^0.3.0
  ormed_sqlite: ^0.4.0
```

  </TabItem>
  <TabItem value="postgres" label="PostgreSQL">

```yaml
dependencies:
  ormed: ^0.3.0
  ormed_postgres: ^0.3.0
```

  </TabItem>
  <TabItem value="mysql" label="MySQL / MariaDB">

```yaml
dependencies:
  ormed: ^0.3.0
  ormed_mysql: ^0.3.0
```

  </TabItem>
</Tabs>

Then resolve the packages:

```bash
dart pub get
```

Do not add `build_runner`, `ormed_cli`, or a generated registry just to use
the direct database facade. Those belong to later paths.

## Choose Your Path

### Start without code generation

If you need raw SQL, schema operations, transactions, or ad-hoc table queries,
continue with [Direct Database Access](./direct-database). It requires only
the runtime package and a driver.

### Use generated models

If your domain is ready for annotated models and generated types, continue with
[Code Generation](./code-generation) for the generator tooling and generated
artifacts, then follow [Quick Start](./quick-start) for the complete model,
migration, seeder, and CRUD path.

The generator itself uses `build_runner`. The Quick Start CLI commands use
`ormed_cli`; its local/global installation and command behavior are documented
in [CLI Overview](../cli/overview).

### Integrate an existing app

If the application already has a schema, runtime, or migration owner, use
[Adopt Ormed In An Existing Project](./adopt-existing-project) instead of
starting with the generated-model walkthrough.

## Verify the Installation

Confirm that the runtime package and selected driver resolve cleanly:

```bash
dart pub get
dart analyze
```

The remaining checks depend on the path you chose:

- Direct path: connect with the driver helper in [Direct Database Access](./direct-database).
- Generated path: run the generator checks in [Code Generation](./code-generation).
- CLI path: verify the command runner in [CLI Overview](../cli/overview).
